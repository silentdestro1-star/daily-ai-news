### Introducing next-generation audio models in the API
*Source: OpenAI Blog*

OpenAI's API now exposes **controllable TTS** via natural language style prompts (e.g., "speak like a sympathetic agent"), moving beyond static speaker embeddings to zero-shot prosody and affect conditioning. This shifts voice agent development from stitching pre-recorded styles or fine-tuning per persona to **inference-time behavioral steering**, drastically reducing latency and data requirements for dynamic conversational UIs. For builders, it means a single model checkpoint now handles diverse speaking styles previously requiring distinct models or complex SSML engineering.
