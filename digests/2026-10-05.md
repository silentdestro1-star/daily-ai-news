### Workspace agents
*Source: OpenAI Blog*

ChatGPT now supports persistent, tool-using agents ("Workspace agents") that maintain context across sessions and execute multi-step workflows by chaining native tools (code interpreter, browsing, file I/O) and custom actions via function calling. This shifts the paradigm from single-turn prompting to stateful, autonomous task execution within a shared team environment, effectively turning the chat interface into a programmable runtime for RAG pipelines, data analysis, and API orchestration. For developers, it reduces the glue code needed to build agentic systems by offloading memory, tool routing, and session management to the platform layer.
