### The Instruction Hierarchy: Training LLMs to Prioritize Privileged Instructions
*Source: OpenAI Blog*

Current LLMs treat all input tokens equally, allowing malicious user prompts (injections/jailbreaks) to override system instructions. This paper formalizes an **Instruction Hierarchy**—explicitly ranking System > User > Tool messages—and trains models via **context distillation** (generating safe completions for attacks using a strong teacher) and **automated data generation** for hierarchy-specific attack vectors. It matters because it shifts defense from heuristic prompt engineering to a learned, structural prior, achieving near-immunity to tested injection attacks with minimal capability regression.

[Read original](https://openai.com/index/the-instruction-hierarchy)
