### OpenAI and Cisco introduce Shirudo
*Source: OpenAI Blog*

OpenAI and Cisco released **Shirudo**, an open-source Linux runtime that enforces memory safety and control-flow integrity (CFI) on unmodified binaries via load-time binary rewriting and `userfaultfd`-based sandboxing. It lets you deploy exploit mitigations (like W^X enforcement and ROP gadget elimination) instantly on running production workloads—containers, VMs, or bare metal—without recompiling code or waiting for vendor patches. This shifts vulnerability response from "patch and reboot" to "mitigate at runtime," critical for securing inference servers and training clusters where uptime is non-negotiable.

[Read original](https://openai.com/index/introducing-shirudo)
